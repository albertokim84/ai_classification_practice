분류 모델 시뮬레이터

로지스틱 회귀(Logistic Regression)와 결정 경계

💡 시뮬레이터 실습 팁

  • 데이터 입력: 아래 '실습 탭'에서 그룹 A(빨강) 또는 그룹 B(파랑)를 선택하고 빈 캔버스를 터치하여 데이터를 생성하세요.
  • 결정 경계 관찰: 서로 다른 두 그룹의 데이터가 모이면, 컴퓨터가 두 그룹을 나누는 최적의 선(결정 경계)을 스스로 학습해 그려냅니다.
  • 방정식의 변화: 데이터를 추가할 때마다 화면 하단의 수식(w1*x + w2*y + b = 0)이 실시간으로 변하는 것을 확인해보세요.
  • 오분류(예외) 실험: 빨간색 영역 깊숙한 곳에 파란색 점을 찍어보세요. 예외 데이터가 경계선에 어떤 영향을 주는지 관찰할 수 있습니다.

⚙️ 실습 탭

데이터: 0개
실시간 결정 경계 방정식:
데이터를 2개 이상 입력해주세요.
